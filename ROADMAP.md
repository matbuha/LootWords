# Roadmap

This roadmap is intentionally broad. It is here to show the main development directions, not to act as a sprint board.

## 1. Core learning games

Priority direction:

- add more image-first and speech-supported mini-games
- strengthen direct vocabulary reinforcement, not just reaction/memory play

Examples:

- Tap the Word
- Repeat After Me
- Sequence Memory
- Image Reveal

## 2. Reward loop and progression

Priority direction:

- deepen motivation without making the system noisy or confusing

Examples:

- Daily Challenge
- Card Evolution
- clearer milestones
- stronger collection goals

## 3. Cards, art, and image pipeline

Priority direction:

- move from placeholder/icon-led visuals toward stronger child-friendly art

Examples:

- custom card illustrations
- better category identity
- cleaner image replacement workflow
- rarity polish that supports image clarity

## 4. Speech and pronunciation

Priority direction:

- improve spoken English support because it is a core learning system, not a bonus feature

Examples:

- better English voice handling
- clearer repeat/replay interactions
- smoother speech timing in learning and gameplay contexts

## 5. Optional fun mini-games

Priority direction:

- add optional familiar games without letting them replace the vocabulary core

Examples:

- Tetris clone
- 2048
- Snake
- Flappy Bird clone

## 6. Parent Mode growth

Priority direction:

- make content and progress management more useful without turning the project into an admin product

Examples:

- better pack controls
- safer import/export
- clearer summaries
- future custom pack support

## 7. Mobile, accessibility, and polish

Priority direction:

- continue improving touch comfort, readability, and content-first layout

Examples:

- mobile play-area tuning
- stronger accessibility defaults
- clearer visual hierarchy on smaller screens

## 8. Contributor infrastructure

Priority direction:

- keep the project easy for outside developers to understand and extend

Examples:

- better contributor docs
- clearer architecture notes
- more current task/status docs
- examples for adding new games or card packs
